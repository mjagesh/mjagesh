## 🚀 Featured Projects

### 📋 JobTrack – Job Application Tracker

A full-stack job application tracking platform built to help users organize and manage their job search in one place.

JobTrack provides a dashboard to monitor application progress, manage job applications, track interview schedules, maintain interview notes, and view application analytics.

**Key Features:**
- User registration and login with JWT authentication
- Dashboard with application statistics
- Create, view, update, and delete job applications
- Track application statuses: Applied, Interview, Offer, and other supported statuses
- Search, filtering, and pagination
- Interview scheduling and notes
- Analytics and application progress charts
- Responsive user interface

**Tech Stack:**
Next.js · React.js · TypeScript · Tailwind CSS · Node.js · Express.js · MongoDB Atlas · JWT · REST APIs

**Architecture:** Separate frontend and backend applications maintained in a single GitHub monorepo.

🔗 **Live Application:** https://job-track-sandy-one.vercel.app/

⚙️ **Backend Deployment:** https://jobtrack-backend-pw33.onrender.com/

📂 **GitHub Repository:** https://github.com/mjagesh/JobTrack

**Deployment:** Vercel (Frontend) · Render (Backend) · MongoDB Atlas (Database)
